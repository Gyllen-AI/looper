Changing the canon, this tree, or the machinery that delivers them.

- **Written is not delivered.** Before calling a doctrine change done, name the
  path by which it reaches the model, and run it. `tests/canon.test.ts` and
  `tests/plan-is-true.test.ts` hold the two halves of that.
- **A number inherited is a number unmeasured.** Measure against this repo,
  write the number and the date down, and gate it with a test.
- **The always-on tier is paid every turn and stays small.** A line that only
  matters during one kind of work belongs in that work's branch; a branch too
  broad to be selective is two branches. The hook itself caps this at ten
  thousand characters, so the canon cannot grow — only be chosen.
- **The project half instantiates the canon and never repeats it.** Prose does
  not hold that; scarcity does. A new line has to say what it replaces.
