What a thing costs, decided when it is written.

- **Cost is a property to state, not to discover:** per request, per row, per
  frame. Per-row work inside a loop over an unbounded set is the incident, and it
  is invisible at the size you tested.
- **A measurement carries the number, the date and the machine.** A benchmark on
  a laptop is not a claim about production.
- **An asset is stored at the size it is used.**
- **Nothing is optimised before it is measured, and nothing large ships without
  being measured once.**
- **A budget with no enforcement point is a wish.** Say where the number is
  checked.
