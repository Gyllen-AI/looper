Deciding the shape before any of it is written.

- **Decide the shape before the code: the data, the boundaries, and what crosses
  between them.** Code written before the shape is decided has to be found and
  undone later, by someone who cannot read it.
- **Write the shape down where the next person will look**, not in a commit
  message and not in your head. A shape nobody can find is a shape that gets
  invented a second time, differently.
- **Check it against the three hardest questions the product already asks.** A
  shape that cannot answer one of them is wrong however clean it looks, and the
  cost of learning that later is every row already stored in it.
- **Name what it refuses.** A shape that permits everything has decided nothing,
  and the thing it should have refused arrives as data nobody can reject.
